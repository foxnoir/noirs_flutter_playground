# Badges

One folder for every README in this playground. Run after changing labels or colors:

```
python3 assets/badges/generate.py
```

Official brand colors stay official. Everything else uses purple, blue, turquoise, pink, or green — not orange, red, or yellow.

After you copy an app into its **own** git repo, copy this folder to `assets/badges/` there and point the README badge links at that path.
